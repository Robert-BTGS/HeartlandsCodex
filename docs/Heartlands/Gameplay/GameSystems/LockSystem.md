# Lock System

* Locks can be opened only via keys or via spells from the Alteration School of Magic.
* Possessing a correct key in inventory auto-unlocks the door when you grab it; without the key, the door cannot be opened.
* The same rules apply to containers (e.g., chests).
* Locks have tiered difficulty levels; including very easy, easy, average, very hard, and a separate category that requires a key.
