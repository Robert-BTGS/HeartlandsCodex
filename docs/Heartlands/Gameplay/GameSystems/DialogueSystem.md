# Dialogue System

* To start a conversation, the player must be within dialogue range and wave at the character.
* The interface is a physical scroll with options on cards.
* The left side displays conversation categories such as information about the NPC, the dialogue minigame, training, and services.
* The right side displays specific options based on the category selected from the left.
* For general dialogue, options for starting quests or getting general information about the world appear automatically when waving to a character.
