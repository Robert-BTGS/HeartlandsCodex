# Enchanting System

* Single enchanting workbench handles both weapons and armor
* Approach triggers pillars from walls as part of the UI presentation
* Left panel lists all spells; right panel lists heart shards in inventory
* Item placement: object from inventory shrinks, floats, and rotates at table center
* Auto-swap of left-hand spell to enchanting ray upon approach
* Casting: hold magic on left hand and aim at the crystal above head
* Materials: heart shard determines enchantment quality level; spell determines effect type
* Up to three enchantments per item; each added enchantment increases minigame difficulty
* Minigame: while casting, grab heart shard and strike appearing runes on the table with the shard
* Success: enchanted object granted
* Failure logic scales with enchanting skill: possible item damage or simple failure
* On failure, the heart shard is lost and the process must be retried
