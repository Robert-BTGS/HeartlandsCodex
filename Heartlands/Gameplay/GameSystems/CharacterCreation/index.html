Character Creation

  1. Players first choose from a list of races.
  2. Races provide different abilities and skill bonuses.
  3. Players then choose from a list of classes.
  4. Classes grant different bonuses depending on class focus.
  5. If predefined classes are unsuitable, players can create their own class.
  6. Players can pick a body type between male or female.
